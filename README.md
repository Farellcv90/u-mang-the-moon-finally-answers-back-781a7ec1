One line, spoken as the Moon answering back at last to everyone who has ever stared up at it — the wishes, the howls, the late-night promises: "I've heard every wish, every howl, every 2 a.m. promise for four billion years — so tonight I'm making one of my own: I'm off the clock." This Python 3 program writes that single line to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```
